# FitLog: Workout Tracker (MERN Stack)

FitLog is a full-stack workout tracker. Log workouts, edit or delete them, filter by type, and see a weekly summary with a goal progress bar and streak counter.

## Features
- Add, view, edit and delete workouts (full CRUD)
- Filter workouts by type
- Weekly goal with progress bar (saved in the browser)
- Current and best workout streak
- Weekly summary by workout type
- Motivational quote box
- Responsive layout (mobile, tablet, desktop)

## Tech stack
- Frontend: React (Vite), React Router, Axios, Bootstrap
- Backend: Node.js, Express
- Database: MongoDB with Mongoose
